# SAHLABU

Mizo Christian hymn book mobile app built with Flutter.

## Features
- Offline hymn data using local JSON
- Search by hymn number, title and lyrics
- Hymn detail screen
- Verse and chorus formatting
- Favorites/bookmarks
- Dark/light mode
- Adjustable lyric font size
- Material 3 UI

## Run
flutter pub get
flutter run

Actual hymns go in assets/data/hymns.json.
